# Portfólio Pessoal / Karina Aparecida

## Descrição:

Portfólio Pessoal, contendo projetos desenvolvidos, linguagens em andamento, informações pessoais e informações para contato, criado com o auxílio do Bootstrap, HTML5 e CSS.

# Recursos Novos 

Como recursos adicionais, optei por incluir duas novas seções: a seção "Conhecimentos" e a seção "Linguagens". Em "Conhecimentos", adicionei as linguagens que já aprendi, enquanto em "Linguagens", as que estou aprendendo.
Para a criação das duas seções, foi utilizado como base o elemento <section>, utilizando containers e personalizando-os de acordo com a minha visão criativa.
